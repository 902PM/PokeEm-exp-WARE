# 概要

完全に方針変更して、JP版と同じ文字コードに変えて、アルファベットの一部を捨てるプロジェクト。  
どうせ使ってない上に、そもそもゲーム内で入力する術がないんだからいらないです。  
GAME_LANGUAGEをJPにして、完全に内部的にJP化します。色々めんどいんで{JPN}から脱却します。  
点字は……どうしよう……？  
  
# 中身
  
1.文字コードを完全JP化。それでも一部の文字はJPにも存在する。  
  
2.基本優先権は日本語、{ENG}つけた時だけ英語フォントが使える。（&や%など、そちらにしかなく、有益な文字なのでそれは残す）  
  
3.フォントは画面UIの都合でもない限り、基本的に日本語フォントを使用する(特に数字と英字)  
  
4.その上で、ブランチ元のように自分でいじらず、初期状態にする。（ただしバグ修正のために変更を加えることはある）  
→ちなみに、とは言うものの、include/configはある程度いじります。（インペリアルシステムとか害悪なんで）  
  
# 自分の技術では不可能なこと

- ふしぎなもらいものの機能（まあ、いらないだろうけど）

- トレーナーヒルの内容。元々のプログラムを逆アセするか、自分で作るしかないのでやりません。（どっかにunusedあったりしてな！！）

- （ホントはやろうと思えばいけるけど）JP版だけ敵のLv表示が『:』が入っている。でもヘルスボックスはスプライトかつ２分割されていて、かつギミックのマークが入ることで幅がたらないので、今のままいじらない。『：』ごときで、多方面に迷惑かけまくる。

# Expantionだからムリなこと

- 戦闘画面等の文字の配置。これは追加要素の関係で位置がズレているためいじれない。

- ステータス画面における、細部のグラフィック。Binをいじらないとダメだからやらない。

- HGSS図鑑における、『マホミルの進化方法』これ英語でも入んの？

- JP化により、フォント8になった弊害による、数値のサイズ。急に１つだけ細文字になっているのはサイズのせい。

- ステータスにおける特性の文字サイズ。これは後の世代の文字が長いから。(7pxで18文字ぐらいが限度なため)

- 戦闘時の技詳細画面（特に命中）、これはそもそも7pxでもムリだからムリ。

- HGSS図鑑のタマゴグループ(すいちゅう1/すいちゅうX)や、特性・技説明の表示。7pxで入らないんだからムリです。

- わざマシンは3桁になったため、技名の長さと幅の関係で不可能です。BW仕様でいいよね。
