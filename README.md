# 概要

フォーク元のセリフを日本語化しただけ。（RG対応）  
文字コードは完全に日本と同じで、フォントも日本語にしている。 
元々英語にあった特殊アルファベットは使い道ないのでいらない。  
"%"や"&"は有能なので、残す。という形。  
GAME_LANGUEGE = JAPANESEにして、誰も参照できない設定言語をJP化。  
日本語に優先権を与えているので、テキストに{JPN}がいらない。  
  
# 中身
  
1.ここから生成できる３作の全てのテキストを日本語化。  

2.文字コードの並びをJPと同じにする。これに伴い、元々あった一部の特殊アルファベットを削除。  
  
3.優先権は日本語、何もつけてなければ日本語、{ENG}つけた時だけ英語フォントが使えるようにする。（&や%などが英語のみなため。）  
  
4.フォントは画面UIの都合でもない限り、基本的に8pxのJPフォントを使用する。(一部に7pxを使用)  
  
5.テキスト以外は基本的にバニラ状態。ただし、フォーク元が抱えているバグは修正済み。またインペリアルシステムとかいう害悪システムを廃止。メートル法に変更。  
  
5.(書いとかないと忘れるので)FONT_NARROWはJPではただの7pxフォントに変貌。これで無理矢理、枠の制限を突破します。  
  
6.数字系がJPN状態だと普通に入らないので、ENG状態にして無理矢理突破。  
  
# 自分の技術では不可能なこと

- ふしぎなもらいものの機能（まあ、いらないだろうけど）

- トレーナーヒルの内容。元々のプログラムを逆アセするか、自分で作るしかないのでやりません。（どっかにunusedあったりしてな！！）

# Expantionだからムリなこと

- 戦闘画面の敵だけの『Lv:XX』表記。スプライトでかつ、２分割されていてかつ、ギミックアイコンが入るためムリ。  
→確認した所、RS時代には英語版も『Lv:XX』表記だったが、Emから捨てたらしい。  
  
- ステータス画面における、細部のグラフィック。Binをいじらないとダメだからやらない。  
→これもよーく見比べると、微妙に違う。(見比べなくても違和感ある)  
  
- HGSS図鑑における、『マホミルの進化方法』←これ英語でも入んの？  
  
- HGSS図鑑のタマゴグループ(すいちゅう1/すいちゅうX)や、特性・技説明の表示。7pxで入らないんだからムリです。  
  
- HGSS図鑑による、技の覚える手段の文字オーバー（とくにわざマシン。英語だとTM/HMなのズルだろ。）  
  
- わざマシンは持てる数が3桁になったため、技名の長さと幅の関係で不可能です。BW仕様でいいよね。  
  
- その他、英語→日本語による文字数の関係で、枠に収まらないテキスト。（できるだけ、7pxや文字数変えて対処はしているが、ムリなもんはムリ）
