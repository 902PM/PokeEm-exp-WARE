# 自分の技術では不可能なこと

- ふしぎなもらいものの機能（まあ、いらないだろうけど）

- FONT_BOLDによる太字。プログラムの中身がめんどい。なら私はFONTから太字にします。

- トレーナーヒルの内容。元々のプログラムを逆アセするか、自分で作るしかないのでやりません。

- タイトル画面の滑らかな動き。今、カクっと動くけど、これが限界です。（AIに聞けばいけるかも？）

# Expantionだからムリなこと

- 戦闘画面等の文字の配置。これは追加要素の関係で位置がズレているためいじれない。

- ステータス画面における、もろもろのUI。これも追加要素と、グラフィックはBinをいじらないとダメだからやらない。
