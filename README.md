# 概要

基本的には、WAREからオリジナル要素を抜いたプロジェクト。  
文字コードは完全に日本と同じで、フォントも日本語にしている。 
元々英語にあった特殊アルファベットは使い道ないのでいらない。  
"%"や"&"は有能なので、残す。という形。  
GAME_LANGUEGE = JAPANESEにして、誰も参照できない設定言語をJP化。  
日本語に優先権を与えているので、テキストに{JPN}がいらない。  
  
# 中身
  
1.文字コードを完全JP化。これに伴い、元々あった一部の特殊アルファベットを削除。  
  
2.優先権は日本語、何もつけてければ日本語、{ENG}つけた時だけ英語フォントが使えるようにする。（&や%などが英語のみなため。）  
  
3.フォントは画面UIの都合でもない限り、基本的に8pxのJPフォントを使用する。(一部に7pxを使用)  
  
4.文字以外の中身はバニラにExpanionの機能が追加されている状態にする。（ただし、バグ修正のために変更を加えることはある）  
→とは言うものの、include/configはある程度いじります。（インペリアルシステムとか害悪なんで）  

5.(書いとかないと忘れるので)FONT_NARROWはJPではただの7pxフォントに変貌。これで無理矢理、枠の制限を突破します。  
  
# 自分の技術では不可能なこと

- ふしぎなもらいものの機能（まあ、いらないだろうけど）

- トレーナーヒルの内容。元々のプログラムを逆アセするか、自分で作るしかないのでやりません。（どっかにunusedあったりしてな！！）

# Expantionだからムリなこと

- 戦闘画面等のヘルスボックス文字の配置。これは追加要素の関係で位置がズレているためいじれない。(本当は敵のLvには『:』がついている)

- ステータス画面における、細部のグラフィック。Binをいじらないとダメだからやらない。

- HGSS図鑑における、『マホミルの進化方法』これ英語でも入んの？

- HGSS図鑑のタマゴグループ(すいちゅう1/すいちゅうX)や、特性・技説明の表示。7pxで入らないんだからムリです。

- HGSS図鑑による、技の覚える手段の文字オーバー（とくにわざマシン。英語だとTM/HMなのズルだろ。）

- わざマシンは持てる数が3桁になったため、技名の長さと幅の関係で不可能です。BW仕様でいいよね。

- その他、英語→日本語による文字数の関係で、枠に収まらないテキスト。（できるだけ、7pxや文字数変えて対処はしているが、ムリなもんはムリ）

# バグ

- {JPN}がついているからか、元々のバグなのか、再現性がまるでないが、戦闘中にバッファの関係でクラッシュする。（不確定要素が非常に大きい）

- アダンのバッファ問題。これはMapsフォルダのルネジムのScriptsの中でも言われている。こちらもバッファなせいで再現性がない。

- エントリーコールを登録できるトレーナーが初回撃破後に登録する旨を話すテキストボックスで、NPCがロックされず、くるくる回ったりする。

- 120ばんどうろで、スプライトが多くてクラッシュする……となっていたが、なんかしなくなった。これまた、不確定要素に逆戻り。

- バトル施設に限り、ダイマックスとテラスタルを問答無用でしてくる。しかも、同じ１匹で両方ともしてくる。全ギミックの環境が原作にはまだないので、不確定だが、１度にギミックは全部合わせて１回までが通例だろ。あと何かしらがバグっているのか、単にこちら側が弱いのか、死ぬほど敵が固い。条件が使用可能フラグとか一切見ていないので、フォーク元がなんとかしてくれないとムリ。
